# 梦灵塔防 (TFGame)

## 项目简介

梦灵塔防是一款基于 SDL2 开发的 2D 塔防类游戏。玩家需要建造不同类型的防御塔，抵御多种敌人的进攻，保卫基地不被攻破。游戏融合了传统塔防与角色扮演元素，玩家可以直接控制角色在地图上移动并使用技能，为策略防御增添了动作元素。

## 技术栈

### 核心技术
- **C++11/14** - 利用现代 C++ 特性，如 Lambda 表达式、智能指针和标准库容器
- **SDL2** - 跨平台多媒体开发库，用于窗口创建、图形渲染和事件处理
- **SDL_image** - SDL 图像加载扩展库，支持多种图像格式(PNG, JPG等)
- **SDL_ttf** - SDL 文本渲染扩展库，用于游戏中文本的显示
- **SDL_mixer** - SDL 音频处理扩展库，用于背景音乐和音效管理
- **SDL2_gfx** - SDL 图形原语扩展库，用于绘制高级图形元素
- **cJSON** - 轻量级 JSON 解析库，用于配置文件的读取和解析

### 设计模式
- **单例模式** - 应用于各管理器类(GameManager, ResourcesManager等)
- **观察者模式** - 用于事件处理和游戏对象间的通信
- **工厂模式** - 用于创建不同类型的游戏对象(敌人、防御塔等)
- **组件模式** - 游戏对象的功能拆分和组合

## 系统架构

### 管理器系统
- **GameManager** - 游戏主循环管理，负责初始化、更新和渲染流程
- **ResourcesManager** - 资源管理，负责加载和提供游戏资源(纹理、音频、字体)
- **ConfigManager** - 配置管理，从 JSON 文件加载游戏配置
- **EnemyManager** - 敌人管理，控制敌人的生成、更新和销毁
- **TowerManager** - 防御塔管理，负责防御塔的放置、升级和攻击逻辑
- **PlayerManager** - 玩家角色管理，处理玩家输入和行为
- **BulletManager** - 子弹管理，处理所有投射物的物理和碰撞
- **WaveManager** - 波次管理，控制敌人的生成时机和数量
- **CoinManager** - 金币管理，处理游戏经济系统

### 核心组件
- **Map** - 游戏地图系统，包含地形数据和寻路算法
- **Tower** - 防御塔基类，派生出 ArcherTower、AxemanTower 和 GunnerTower
- **Enemy** - 敌人基类，派生出多种敌人类型(史莱姆、骷髅、哥布林等)
- **Animation** - 动画系统，处理游戏中的精灵动画
- **Timer** - 计时器系统，用于游戏中的时间管理和事件触发
- **Vector2** - 二维向量类，用于位置和方向计算
- **UI** - 用户界面系统，包括状态栏、面板和游戏结束横幅


### 项目结构
```
TFGame/

├── tower/            # 防御塔类

├── UI/               # 用户界面类
├── coin/             # 金币系统

├── config/           # 配置文件
│   ├── config.json   # 游戏基本配置
│   ├── level.json    # 关卡配置
│   └── map.csv       # 地图数据
└── 核心文件(.h/.cpp)  # 游戏核心组件
```

### 如何扩展

#### 添加新防御塔
1. 在 `tower_type.h` 中添加新的塔类型枚举
2. 创建继承自 `Tower` 的新塔类
3. 在 `ResourcesManager` 中加载相关资源
4. 在 `config.json` 中添加新塔的属性配置
5. 在 `TowerManager` 中添加创建和管理新塔的代码

#### 添加新敌人
1. 在 `enemy_type.h` 中添加新的敌人类型枚举
2. 创建继承自 `Enemy` 的新敌人类
3. 在 `ResourcesManager` 中加载相关资源
4. 在 `config.json` 中添加新敌人的属性配置
5. 在 `level.json` 中添加新敌人的生成规则

## 技术亮点

1. **高效的渲染系统** - 使用 SDL2 硬件加速渲染和垂直同步
2. **灵活的动画系统** - 支持循环、单次播放和回调函数的动画框架
3. **可扩展的游戏对象架构** - 基于继承和组合的灵活设计
4. **数据驱动设计** - 所有游戏参数通过 JSON 配置文件管理，易于调整和平衡
5. **完善的音效和音乐系统** - 使用 SDL_mixer 实现丰富的音频体验
6. **精细的游戏状态管理** - 基于有限状态机的游戏流程控制
